# RunnerX

RunnerX benchmarks GitHub-hosted runners across realistic CI workloads, making the trade-offs between speed, cost, architecture, and hardware easier to see.

![RunnerX cost and performance dashboard](/assets/screenshots/runnerx.png)

It compares runner SKUs across scenarios including cache restores, CodeQL, Docker, Go, Gradle, Next.js, Rust, test suites, the Actions Toolkit, and Vue. The dashboard helps identify where a larger runner pays off and where a cheaper option performs just as well.
